Explore CodeLens AI

Tools to help you
understand your code.

Explore the features available in the CodeLens workspace. Paste in a JavaScript snippet to try the built-in checks, explanations, step-through view, and CodeBot chat.

What you can do

🐛

Analyze common issues

Check JavaScript snippets for a few recognizable problems, including possible division by zero and array loops that may run one step too far. Review the suggestions alongside your code.

💡

Get a code explanation

Choose Beginner, Student, or Developer mode, then ask the workspace to explain familiar patterns such as variables, loops, conditions, and functions.

▶️

Walk through code

Use Step-by-Step to display non-empty lines in sequence, helping you follow the order in which instructions appear in your snippet.

🔧

Review a suggested fix

Auto Fix demonstrates a couple of targeted JavaScript edits. Inspect the suggested code before copying it or using it in your project.

📊

Check code health

See a score based on the issues and warnings detected by the analyzer, plus a quick X-Ray summary of code length and findings.

🤖

Ask CodeBot

Ask starter questions about bugs, loops, functions, variables, and explanations. CodeBot offers guidance based on the question and the code in the editor.

🖥️

Run JavaScript snippets

Try a JavaScript snippet in the workspace and view captured console output or runtime errors. Run only code you trust.

📄

Start with an example

Load the built-in sample to explore the editor and try the analysis, explanation, and run controls without writing a snippet first.

Get started in three steps

1 Open the workspace Go back to the homepage and scroll to the code workspace.
2 Add a code snippet Paste your JavaScript or load the example to explore the controls.
3 Choose a tool Analyze, explain, step through, run the snippet, or ask CodeBot a question.
